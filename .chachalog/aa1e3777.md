Deprecated the `createVersion` field on JCR node mutations: it no longer creates a JCR version and always returns `false`. Files stay versionable and are still versioned at publication time — only the extra upload-time checkpoint and its `uploaded_at_*` label are gone. Use the [content-versioning](https://github.com/Jahia/content-versioning) module instead (Jahia 8.2.4.0+). The field is kept in the schema as an inert no-op so existing callers keep working. (#626)
